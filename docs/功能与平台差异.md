# 功能与平台差异

核查日期：2026-11-04。源码基线：宿主 `c768cb12c86e59b60fbc69149013850edce509b0`；修复版本 `1.0.1` 待发布。生产 Kotlin 源码与通用测试逐字节迁移；仅独立化构建、发布与 Maven 消费接线，宿主扫描器留宿主。`1.0.0` 已发布，但 JitPack 将 compiler 的 sources 变体指向主 JAR，造成 size/hash 冲突，公开元数据验收未通过；`1.0.1` 只修复发布正规化，不改变 Kotlin API 或运行时行为。

## 分层与 API 边界

| 模块 / 能力 | Android | iOS | OpenHarmony | JVM / 宿主责任 |
| --- | --- | --- | --- | --- |
| `routing-core` / `RouteDefinition`、`RouteRegistry` | commonMain | commonMain | commonMain | JVM 11；宿主提供定义、序列化与 normalize |
| `parsePublic` / `publicUri` | 相同 | 相同 | 相同 | HTTPS 精确 host 或宿主 Scheme + `page` host；仅 `PUBLIC`；公开参数投影和正值校验 |
| 信封 `encodePublicTarget` / `decodePublicTarget` | 相同 | 相同 | 相同 | 可处理 `PUBLIC` / `RENDERER`，拒绝 `INTERNAL`；**可信调用方认证由宿主完成** |
| `parseInternal` / `internalUri` / `decodeInternalTarget` | 相同 | 相同 | 相同 | 仅可信内部入口使用；嵌套 JSON 不输出到外链或日志 |
| 参数预算与严格类型 | 相同 | 相同 | 相同 | 公共 URI/输入信封 16 KiB，输出信封预留后 12 KiB；内部 URI 512 KiB；单字符串公开 4096 bytes、内部 64 KiB；拒绝非法 UTF-8 与重复已知参数 |
| `RoutePresentation` | 相同 | 相同 | 相同 | 默认无覆盖；标题 ≤200 字符、禁控制字符，showTitle 仅 true/false；宿主决定是否允许展示覆盖 |
| `runRouteInterceptors` | 相同 | 相同 | 相同 | 请求与结果由宿主定义；每帧最多放行一次，返回后关闭，取消继续传播 |
| `RouteRegistrySpec` / `PageRegistrySpec` | 源注解 | 源注解 | 源注解 | 源码声明契约；每种注册表唯一 expect object |
| `routing-compiler` 两个 KSP provider | 构建时 JVM | 构建时 JVM | 构建时 JVM | JVM 21，不随手机运行时分发；校验重复/重叠路径、字段、类型、遗漏注册、页面绑定与宿主保留名 |
| 原生入口与 UI | 宿主 Intent | 宿主 Universal Link | 宿主 Want | 组件不提供页面、Kuikly Module、平台导航或生命周期 owner |

宿主自己的访问等级、品牌与功能枚举、页面保留名、登录/隐私状态均不迁入组件。仅通用解析不能证明真实来源，KSP 静态校验也不能替代运行时业务准入。
